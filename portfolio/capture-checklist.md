# Screenshot Capture and Privacy Checklist

- Capture the validated source revision against freshly reset canonical data.
- Use 1440px desktop for My Work, Scope, Changes, and Activity; use 390px mobile for Overview and Deliverables.
- Hide browser extensions, account avatars, provider consoles, terminal windows, and operating-system notifications.
- Confirm every person, organization, address, comment, link, and filename is canonical synthetic data.
- Check for credentials, reset secrets, signed URLs, invitation recipients, prompts, diagnostics, or private attachment URLs.
- Verify focus is not accidentally visible, content is sharp, framing is consistent, and no control is clipped.
- Upload to the dedicated public portfolio folder, record dimensions and source commit in the manifest, and test each HTTPS URL in a clean signed-out browser.
